# Инструкция по настройке прыжка в Unity

## Проблема
Персонаж не прыгает. Возможные причины:
1. В Animator Controller отсутствует параметр "Jump" типа Trigger
2. Неправильно настроены переходы между состояниями
3. Персонаж не определяется как grounded

## Шаг 1: Проверка параметров Animator Controller

1. Откройте **Animator** окно (Window → Animation → Animator)
2. Выберите ваш персонаж в сцене
3. В левой панели найдите раздел **Parameters**
4. Проверьте, есть ли параметр с именем **"Jump"** типа **Trigger**
   - Если параметра нет:
     - Нажмите **"+"** в разделе Parameters
     - Выберите **Trigger**
     - Назовите его **"Jump"** (точно так же, как в коде)

## Шаг 2: Настройка переходов в Animator Controller

### Переход из "Movement" или "Idle" в "Jump":

1. В Animator Controller найдите состояние **"Movement"** (или **"Idle"**)
2. **Правой кнопкой мыши** на состоянии → **Make Transition**
3. Перетащите стрелку на состояние **"Jump"** (или **"Jump_Up"**)
4. Выберите созданный переход (стрелку)
5. В **Inspector** проверьте условия перехода:
   - **Conditions** должно содержать: **"Jump"** (Trigger)
   - Если условия пустые, добавьте:
     - Нажмите **"+"** в разделе Conditions
     - Выберите параметр **"Jump"**
     - Тип должен быть **Trigger**

### Переход из "Jump" обратно в "Movement":

1. Найдите состояние **"Jump"** (или **"Jump_Down"**)
2. Создайте переход в **"Movement"** или **"Idle"**
3. В условиях перехода установите:
   - **Has Exit Time**: ✅ (включено)
   - **Exit Time**: около **0.9** (чтобы анимация завершилась)
   - ИЛИ используйте условие: **"isGrounded"** (Bool) = **true**

## Шаг 3: Проверка настроек персонажа

### В компоненте ThirdPersonController:

1. Выберите объект персонажа в сцене
2. В Inspector найдите компонент **ThirdPersonController**
3. Проверьте следующие поля:
   - **Animator**: должен быть назначен ваш Animator компонент
   - **Ground Check**: должен указывать на пустой GameObject у стоп персонажа
   - **Ground Mask**: должен содержать слой **"Ground"** (или слой, на котором находится земля)

### Настройка Ground Check:

1. Создайте пустой GameObject под названием **"GroundCheck"**
2. Сделайте его дочерним объектом персонажа
3. Расположите его у стоп персонажа (примерно на уровне ног)
4. Назначьте его в поле **Ground Check** компонента ThirdPersonController

### Настройка Ground Mask:

1. Убедитесь, что пол/земля в сцене находится на слое **"Ground"**
   - Выберите объект пола
   - В Inspector вверху измените **Layer** на **"Ground"**
   - Если слоя нет, создайте: Edit → Project Settings → Tags and Layers → добавить слой "Ground"
2. В компоненте ThirdPersonController в поле **Ground Mask** выберите слой **"Ground"**

## Шаг 4: Проверка анимаций

1. Убедитесь, что анимации прыжка назначены состояниям:
   - **Jump** или **Jump_Up** - анимация подъёма
   - **Jump_Down** - анимация падения
2. Проверьте, что анимации не зациклены (Loop Time должен быть выключен)

## Шаг 5: Тестирование и отладка

1. Запустите игру (Play)
2. Нажмите **Space** для прыжка
3. Откройте **Console** (Window → General → Console)
4. Проверьте сообщения с префиксом **[Jump]**:
   - Если видите "Не могу прыгнуть" - проблема с grounded
   - Если видите "ОШИБКА: Параметр 'Jump' не найден" - проблема с Animator Controller
   - Если видите "Прыгаю!" - физика работает, но может быть проблема с анимацией

## Дополнительные проверки

### Проверка CharacterController:
- Убедитесь, что на персонаже есть компонент **CharacterController**
- Проверьте, что **Skin Width** не слишком большой
- **Min Move Distance** должен быть небольшим (0.001)

### Проверка значений:
- **Gravity**: должно быть отрицательным (например, -9.81)
- **Jump Height**: попробуйте увеличить (например, 2.0 или 3.0)
- **Ground Probe Radius**: попробуйте увеличить (например, 0.3 или 0.4)

## Быстрое решение (если ничего не помогает):

1. В Animator Controller создайте простой переход:
   - Из **Any State** → **Jump**
   - Условие: **"Jump"** (Trigger)
   - **Has Exit Time**: ❌ (выключено)
   - **Interruption Source**: **None**

2. Из **Jump** → **Movement**:
   - **Has Exit Time**: ✅
   - **Exit Time**: 0.9

Это гарантирует, что прыжок сработает при нажатии Space, если триггер установлен правильно.
